# Code of Conduct

## Our standard

Vitrum is an open-source project. Participation is expected to be respectful, constructive and focused on the work.

Participants must:
- use professional and inclusive language;
- disagree with ideas without attacking people;
- give actionable technical feedback and accept corrections;
- respect privacy and avoid publishing personal, confidential or security-sensitive information;
- follow the repository's licensing and contribution rules.

Unacceptable behaviour includes harassment, threats, discriminatory attacks, deliberate intimidation, doxxing, sexualised harassment, persistent personal attacks and knowingly publishing another person's private information.

## Maintainer responsibilities

The project maintainer is responsible for interpreting and enforcing this Code of Conduct. Depending on severity and context, responses may include a warning, removal of content, rejection of a contribution, temporary restriction from project spaces or permanent exclusion from participation.

Decisions should be proportionate to the behaviour and protect the safety of participants and the project.

## Reporting

Report conduct concerns privately to the project maintainer through the contact options on the maintainer's GitHub profile: https://github.com/lolokeksu09

Do not use public Issues to publish private correspondence, personal information or allegations containing sensitive details. Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not this process.

## Scope

This Code applies to project spaces, including Issues, Pull Requests, reviews and other project-related interactions, as well as public spaces when someone is officially representing Vitrum.

This document does not create a guaranteed response time or a promise of individual support.
