## 2.8.3 — интеграция Vitrum Clone в основной пакет (кандидат pre-release)

- **Локализация:** русский и английский интерфейс охватывает главную, журнал, «Щит приватности», нижнюю навигацию, игровой режим, серверы, маршрутизацию, настройки, «О приложении», резервное копирование и диалоги.
- **Безопасность состояния:** операции с серверами и подписками не должны незаметно сбрасывать активный маршрут при подключённом или переходном VPN; демонстрационные данные изолированы от пользовательского профиля.
- **Целостность данных и runtime assets:** GeoData публикуется после проверки SHA-256; остановка Pinger не инициирует JNI для не запущенного процесса; fallback загрузки Xray использует метаданные официального GitHub Releases и сохраняет проверку контрольной суммы.
- **Route preview:** уточнено объяснение catch-all и ранних транспортных ограничений; локальный разбор IPv6 CIDR и порядок правил покрыты точечными регрессиями. Неопределённые DNS/geo/domain/traffic результаты остаются UNKNOWN.
- Основной пакет остаётся `app.rayclient`; `app.rayclient.clone` — отдельная тестовая сборка. Версия приложения повышена до versionCode 283 / versionName 2.8.3.

**Ограничения:** изменения route preview не являются независимым тестом реального VPN-трафика. Работа Xray/TUN, DNS/IPv4/IPv6, failover и kill switch на физическом ARM64-устройстве не подтверждена этой сборкой. Assurance #39 остаётся открытым; физическую приёмку выполняет владелец приложения.

## 2.7.0 — Encrypted DNS 853 Guard и Android Private DNS (pre-release, 2026-11-05)

- DoT TCP/853 и DoQ UDP/853 приложений, включённых в VPN, направляются через Xray раньше общих `direct`, geo/LAN и default-маршрутов.
- Сохранён приоритет пользовательских правил, блокировки IPv6 и режима «Только TCP/UDP»; трафик 853 не расшифровывается и не выдаётся за обычный DNS/53.
- «Щит» по ручному действию показывает предполагаемые маршруты TCP/853 и UDP/853 для настроенных DNS IP по порядку правил Xray, а также режим Private DNS из `LinkProperties` активной сети процесса VITRUM.
- Системный DNS-хост и IP Private DNS **не записываются и не показываются**. Добавлено нормальное системное разрешение `ACCESS_NETWORK_STATE` для чтения активной сети.
- Android 8 отображает «не поддерживается»; отсутствие `LinkProperties` — `UNKNOWN`. DoH/443, нестандартные порты, другие DNS-серверы и исключённые приложения не измеряются.
- Добавлены регрессионные тесты маршрутов TCP/UDP 853, пользовательских исключений, транспортных ограничений и режимов Private DNS.

**Изменение поведения:** соединения на порт 853, ранее попадавшие под общий `direct`, теперь направляются через Xray. Локальный DoT/DoQ DNS может потребовать явного пользовательского исключения; при отсутствии UDP у VPN-сервера DoQ может не работать. Подтверждения отсутствия DNS/IPv6-утечек на телефоне нет.


## 2.6.0 — DNS Route Audit и строгие DNS-адреса (pre-release, 2026-11-05)

- Пользовательские DNS-серверы проверяются как **числовые IPv4/IPv6-адреса**: недопустимые октеты, неполные IPv6, имена хостов и zone ID не попадают в конфиг Xray. Проверка не выполняет сетевой DNS lookup.
- Несколько корректных серверов сохраняются без повторов; неверный текст остаётся в настройках для исправления. Если корректных нет, используется прежний резервный список DNS с явным предупреждением.
- В «Щит приватности» добавлен **ручной аудит DNS UDP/53 и TCP/53**: применяются правила из реального генератора Xray с учётом первого совпадения, пользовательских IP/CIDR и port rules, GeoIP-неопределённости, DNS-out при DoH/FakeDNS/blockV6 и общего direct.
- Отличает ожидаемый proxy, Xray DNS, прямой маршрут, блокировку, смешанные и неопределённые результаты. Это анализ конфигурации **в момент нажатия** — работа TUN, DoH/DoT, Private DNS, приложения вне VPN и отсутствие утечек не подтверждены.
- Добавлены 13 JVM-тестов на IPv4/IPv6-валидность, fallback, user direct/block и консервативный вывод. Исправлена структура маршрутизатора без изменений поведения исключений приложений.

**Совместимость:** пакет, сертификат, TUN, Xray, серверы и форматы профилей неизменны. Изменение поведения — недопустимые пользовательские DNS больше не передаются Xray; если валидных не осталось, автоматически используется прежний публичный резервный DNS. Не включать режим «полная защита» только по локальному аудиту.


## 2.5.0 — DNS Route Guard и диагностика IPv6 (кандидат)

- Обычные DNS-запросы TCP/UDP 53 приложений, включённых в Android VPN, направляются к Xray раньше общих `direct`/геоправил, когда не включён Xray DNS interception (DoH/FakeDNS/blockV6).
- Существующий `dns-out` при DoH, FakeDNS или отключении IPv6 и приоритет явно заданных пользовательских правил сохраняются.
- В «Щите» показана **плановая** политика DNS-маршрутов и ограничения теста IPv6; оценка не объявляет отсутствие DNS/IPv6-утечек.
- В настройках IPv6 убрано категорическое заявление, что утечек точно нет.
- Добавлены JVM-тесты порядка правил, direct/default/block, DNS interception и IPv6 block.
- Сохраняются `app.rayclient`, оригинальная подпись, `::/0`, TUN, Xray и раздельное туннелирование.

**Изменение поведения:** DNS 53 приложений внутри VPN больше не наследует общий прямой маршрут; локальный resolver может потребовать явного правила direct. DoH/DoT и исключённые приложения не перехватываются этим правилом. Реальную IPv6/DNS leak safety на ARM64 ещё нужно проверить.


## 2.4.0 — Privacy Shield 2.0 (4 ноября 2026)

- Оценка настроек отделена текстом от неподтверждённой фактической безопасности DNS и трафика других приложений.
- Ручной запуск диагностики объединяет быстрый просмотр типичных TCP-портов и IPv4/IPv6 HTTP-проверки через приватный Xray Unix-сокет; отдельное сравнение с прямым IP запрашивает согласие.
- Устаревшие результаты портов и IP не считаются успешными: проверяется сервер, VPN-сеанс, смена сети и срок хранения 5 минут.
- Чужой локальный TCP-порт с неизвестным владельцем и совпадение IP дают предупреждение, но не ложно подтверждённую критическую утечку.
- Ошибки IPv4/IPv6 различают таймаут, недоступный сокет и некорректный ответ.
- История до 12 результатов исключительно в памяти процесса: метки времени и категории результатов; без IP, номеров портов, идентификаторов серверов, путей сокетов, ключей и логов.
- Секреты VPN, Android TUN, Xray и подпись приложения не меняются. DNS-проверка остаётся UNKNOWN без независимого наблюдателя.
- Новые JVM-тесты и регрессии достоверности оценок, недействительности старых результатов и состава отчёта.

**Ограничения:** GET через сервисный Xray Unix-сокет использует HTTP; это не HTTPS-проверка и не доказательство DNS/IPv4/IPv6 leak-free, особенно для других приложений. На реальном ARM64 Android не проверено. Выпуск только pre-release.


## 2.3.0 — восстановление после неудачного автопереключения (4 ноября 2026)

- Неудачный запуск Xray кандидата больше не прерывает перебор остальных серверов.
- Если кандидаты не ответили через служебный unix-сокет Xray, выполняется попытка восстановления прежнего сервера с такой же HTTP-проверкой.
- Выбранный сервер сохраняется только после ответа и проверки живого процесса. STOP/новый START отменяют устаревшие результаты, включая откат.
- При неудачном откате TUN остаётся открытым и заблокированным, в том числе при выключенном пользовательском kill switch. Явное отключение VPN по-прежнему закрывает TUN.
- В журнале отдельное событие автоматического отката; оно учитывается как проблема, а не успешная смена сервера.
- JVM-регрессии перебора, отката, блокировки, отмены и счётчиков журнала. Сетевые маршруты, ключ подписи и пакет не менялись.

**Ограничения:** не проверено на устройстве. JVM/CI не доказывают отсутствие DNS/IPv6-утечек, фактическую блокировку трафика или надёжность Wi-Fi↔LTE и Always-on/lockdown. Только pre-release.

## 2.1.0 — Assurance & безопасная смена сервера (3 ноября 2026)

Официальная сборка `app.rayclient`, обновление поверх 2.0.0 при совпадении сертификата подписи. Общие изменения Vitrum Clone и post-2.0.0 перенесены в production source; отдельный пакет `app.rayclient.clone` остаётся только для изолированных тестов.

- Серверы: переключение по нажатию с сохранением Android TUN. Новый Xray должен дать HTTP-ответ через свой unix-сокет прежде, чем обновится выбранный сервер. При ошибке выполняется откат; при невозможности восстановить подключение TUN остаётся заблокированным.
- Assurance: чёткое различие между запущенным Xray и проверенным HTTP-ответом; отмена устаревшего подтверждения после STOP, рестарта и потери сети.
- Роутинг: предварительное объяснение маршрута приложения, домена, IP, порта и протокола; результат не выдаётся за наблюдение фактического трафика.
- Щит: ручные IPv4/IPv6 HTTP-пробы через служебный Xray-сокет; DNS и отсутствие утечек обозначены как UNKNOWN до независимой проверки.
- Исправлены гонки STOP/START, устаревшие watcher/failover-результаты, сетевое восстановление и ложная смена выбранного сервера.

**Ограничения:** GitHub CI, JVM-тесты и Android 16 x86_64 UI smoke не подтверждают работу на ARM64, DNS/IPv4/IPv6 leak-free, Always-on/lockdown и фактический fail-closed при переключении. Вначале публикуется подписанный автором **pre-release** для тестирования на устройстве. Версия stable требует отдельного подтверждения.

## 2.0.0 — Experience & Reliability (31 октября 2026)

Официальная версия `app.rayclient` включает протестированные изменения общего кода из Vitrum Clone. Это обновление VITRUM 1.0.0, **не** новый пакет `app.rayclient.clone`. Поддержка: Android 8.0+, ARM64; Xray 26.3.27 без изменения ядра или семантики маршрутизации.

### Интерфейс и первый запуск
- Onboarding 2.0: три компактных этапа, закреплённые кнопки, прокрутка независимо от футера, безопасные отступы Android 16, шаг назад системной кнопкой.
- Разрешение уведомлений запрашивается по явной кнопке на заключительном шаге, а не всплывающим системным окном при открытии.
- Увеличенные зоны касания (не менее 48 dp), адаптивные сегментированные элементы и нижняя навигация с учётом размера шрифта.
- Главная прокручивается на невысоких экранах; при ошибке соединения доступен журнал.

### Серверы, маршрутизация и защита
- Чёткие состояния выбранного сервера, избранного и пустых результатов фильтрации; улучшена доступность TalkBack.
- Маршрутизация показывает режим «Прочий трафик» и предупреждает о прямом обходе VPN; правила Xray не изменены.
- «Щит» отдельно показывает непроверенные проверки, не представляя их доказанной защитой и не меняя расчёт оценки.

### Настройки, диагностика и надёжность
- Поиск по разделам настроек и пояснениям; результаты диагностики остаются видны при переходе между вкладками.
- Перед копированием диагностических данных добавлено предупреждение об их конфиденциальности.
- Зашифрованное состояние авто-серверов записывается атомарно; чтение резервных копий ограничено по размеру.
- Если Android не разрешил запуск foreground VPN-службы, Xray не стартует и пользователь видит ошибку.
- При обновлениях проверяются версия, тег и сертификат релиза.

### Проверки и ограничения
- PR #35: Android 16 x86_64 UI-эмулятор — первый запуск, Home, Servers, Routing и шрифт 1.0/1.3/1.5; Xray в этом прогоне **не** проверялся.
- Модульные тесты, сборки Debug и Clone ARM64 и проверка идентичности тестового пакета успешно проходили в CI.
- Подписание официального APK допускается **только прежним ключом автора**. Без секрета ключа либо при несовпадении сертификата релиз 2.0.0 блокируется; одноразовый ключ не используется для официального APK.
- Реальные маршруты, DNS/IPv6-утечки, подключение и отключение VPN на устройстве необходимо проверять отдельно; успешные эмуляторные UI-тесты не подтверждают безопасность трафика.

Подробности и контрольные суммы: `docs/releases/v2.0.0.md` и страница GitHub Release `v2.0.0`.
