# Журнал изменений

Версии 1.x выложены в [Releases](https://github.com/lolokeksu09/Vitrum/releases), подробные заметки с контрольными суммами лежат в `docs/releases/`. Версии до 1.0.0 были отладочными пре-релизами и здесь сжаты до списка возможностей. Что из этого проверено на телефоне, а что только запуском и по коду, смотрите в `docs/HANDOFF.md`; если не сказано иного, на устройстве не проверялось.

## 1.0.0
Первая версия с номером 1.0: набор функций и аудит завершены; на телефоне не проверено.
- Лицензия GNU GPL v3 (только версия 3), файл `LICENSE`, перечень сторонних компонентов в `THIRD-PARTY-NOTICES.txt`.
- Тексты интерфейса и документации написаны заново; остались только общие служебные названия («Через VPN», «Белый список», «TCP и UDP»). Раздел «Игры напрямую» называется «Игры мимо VPN».
- «О приложении» и README: отметка о разработке с ИИ-ассистентом.
- GitHub Actions собирает тесты, отладочный и release-APK (R8) по тегу `v*` или вручную и выкладывает пре-релиз. Подпись одноразовым ключом сборки, не ключом автора.

## 0.25.x
- 0.25.43: `GeoSanity` проверяет скачанный `geoip.dat` до замены (`private` только из зарезервированных диапазонов, доля `ru` и `ru-whitelist` в IPv4 не больше 3%).
- 0.25.42: `BootReceiver` слушает смену времени и часового пояса, расписание VPN перепланируется (манифест изменён).
- 0.25.41: `XrayOrphans` убирает осиротевший процесс Xray при подключении и при отключении.
- 0.25.40: слишком широкие правила «напрямую» из маршрутизации панели отбрасываются; приватные уведомления включены по умолчанию; `FLAG_SECURE` ставится до построения экрана.
- 0.25.39: правки по аудиту: белый список ключей в JSON-режиме, `support-url` только по https, `fallback-url` только с публичным именем хоста, сохранение id сервера при обновлении подписки, проверка пользовательских правил до сохранения, перезапуск Xray под замком, срок на чтение ответа подписки.
- 0.25.38: «Трафик по приложениям» («Настройки → Сервис»). Манифест: разрешение `PACKAGE_USAGE_STATS` (включается пользователем в системных настройках).
- 0.25.37: статистика трафика отдельно по мобильной сети; сценарий «Открытая Wi-Fi»; расписание VPN; мастер «Почему не подключается»; «Скорость всех серверов»; фильтр серверов по стране; стратегия балансировщика для авто-серверов.
- 0.25.36: порядок правил маршрутизации (кнопки ▲ ▼).
- 0.25.35: «О приложении → Составить отчёт о проблеме» (отчёт составляется на устройстве, сам не отправляется).
- 0.25.34: «Прочий трафик» у каждого профиля (через VPN, напрямую, блокировать) и другие правки правил маршрутизации.
- 0.25.33: «Перезапускать Xray для Hysteria2» (по умолчанию выключено).
- 0.25.31–0.25.28: необязательные root-функции (по умолчанию выключены, `su` без включения не вызывается): «Чьи это порты», сравнение с эталоном, настройка работы в фоне.
- 0.25.26: «Щит → Что видят другие приложения» (без root).
- 0.25.25: виджет «Подключить / Отключить».
- 0.25.24: тест скорости через Xray.
- 0.25.23–0.25.21: QR-код сервера, лимит трафика за месяц, статистика трафика по дням.
- 0.25.20: проверка обновлений по релизам репозитория, если свой `update.json` не указан.
- 0.25.19: ярлык «Подключить» на значке приложения.
- 0.25.18: «Работа в фоне» (экономия заряда, автозапуск).
- 0.25.17–0.25.12: настройки DNS (TCP, стратегия доменов, поддельный DNS), уровень журнала Xray, MTU туннеля, фильтры маршрутов (реклама, локальная сеть, sniffing), отклик и скорость в уведомлении.
- 0.25.10–0.25.6: доступность (TalkBack, масштаб шрифта), зашифрованная резервная копия `.vitrumbak`, блокировка приложения, «Стереть все данные», приватные уведомления.
- 0.25.5–0.25.3: расширенные проверки «Щита» (другой VPN, VPN-программы, время, источник установки), кнопка «Усилить защиту».
- 0.25.2: пресет «Банки и госуслуги мимо VPN» (исключение приложений из туннеля).
- 0.25.1–0.25.0: новый вид (две вкладки, шторка серверов), фрагментация TLS, укрепление хранения данных и разбора ссылок.
