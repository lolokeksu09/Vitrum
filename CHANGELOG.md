# Журнал изменений

## 2.0.0 — Experience & Reliability (31 октября 2026)

Официальная версия `app.rayclient` включает протестированные изменения общего кода из Vitrum Clone. Это обновление VITRUM 1.0.0, **не** новый пакет `app.rayclient.clone`. Поддержка: Android 8.0+, ARM64; Xray 26.3.27 без изменения ядра или семантики маршрутизации.

### Интерфейс и первый запуск
- Onboarding 2.0: три компактных этапа, закреплённые кнопки, прокрутка независимо от футера, безопасные отступы Android 16, шаг назад системной кнопкой.
- Разрешение уведомлений запрашивается по явной кнопке на заключительном шаге, а не всплывающим системным окном при открытии.
- Увеличенные зоны касания (не менее 48 dp), адаптивные сегментированные элементы и нижняя навигация с учётом размера шрифта.
- Главная прокручивается на невысоких экранах; при ошибке соединения доступен журнал.

### Серверы, маршрутизация и защита
- Чёткие состояния выбранного сервера, избранного и пустых результатов фильтрации; улучшена доступность TalkBack.
- Маршрутизация показывает режим «Прочий трафик» и предупреждает о прямом обходе VPN; правила Xray не изменены.
- «Щит» отдельно показывает непроверенные проверки, не представляя их доказанной защитой и не меняя расчёт оценки.

### Настройки, диагностика и надёжность
- Поиск по разделам настроек и пояснениям; результаты диагностики остаются видны при переходе между вкладками.
- Перед копированием диагностических данных добавлено предупреждение об их конфиденциальности.
- Зашифрованное состояние авто-серверов записывается атомарно; чтение резервных копий ограничено по размеру.
- Если Android не разрешил запуск foreground VPN-службы, Xray не стартует и пользователь видит ошибку.
- При обновлениях проверяются версия, тег и сертификат релиза.

### Проверки и ограничения
- PR #35: Android 16 x86_64 UI-эмулятор — первый запуск, Home, Servers, Routing и шрифт 1.0/1.3/1.5; Xray в этом прогоне **не** проверялся.
- Модульные тесты, сборки Debug и Clone ARM64 и проверка идентичности тестового пакета успешно проходили в CI.
- Подписание официального APK допускается **только прежним ключом автора**. Без секрета ключа либо при несовпадении сертификата релиз 2.0.0 блокируется; одноразовый ключ не используется для официального APK.
- Реальные маршруты, DNS/IPv6-утечки, подключение и отключение VPN на устройстве необходимо проверять отдельно; успешные эмуляторные UI-тесты не подтверждают безопасность трафика.

Подробности и контрольные суммы: `docs/releases/v2.0.0.md` и страница GitHub Release `v2.0.0`.

## 1.0.0
Первая версия с номером 1.0: набор функций и аудит завершены; автор проверил приложение на своём устройстве.
- Лицензия GNU GPL v3 (только версия 3), файл `LICENSE`, перечень сторонних компонентов в `THIRD-PARTY-NOTICES.txt`.
- Тексты интерфейса и документации написаны заново; остались только общие служебные названия («Через VPN», «Белый список», «TCP и UDP»). Раздел «Игры напрямую» называется «Игры мимо VPN».
- «О приложении» и README: отметка о разработке с ИИ-ассистентом.
- Новый ключ подписи выпуска (прежний нельзя использовать: пароль утерян). Сборка 0.24.1 с прежним ключом поверх не обновится: нужно удалить её и поставить новую.
- GitHub Actions собирает тесты, отладочный и release-APK (R8) по тегу `v*` или вручную и выкладывает пре-релиз. Если в секретах репозитория заданы `VITRUM_KS_BASE64` и `VITRUM_KS_PASS`, release подписывается ключом автора (отпечаток сверяется, при несовпадении сборка падает), иначе одноразовым ключом сборки.
