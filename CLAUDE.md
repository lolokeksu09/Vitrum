# Vitrum: инструкции для Claude Code

Полные правила: @AGENTS.md
Состояние проекта: docs/HANDOFF.md (прочитай до работы).

Главное, если файлы выше не подтянулись:
- Отвечай по-русски, коротко. Работай по шагам: закончил шаг, остановился, жди «дальше».
- Помечай, что проверено запуском, а что предположение. Приложение на устройстве проверяет автор; пока не подтвердил, пиши «не проверено на устройстве».
- Секреты (ключ подписи, пароль, токен подписки, настоящие ссылки) не печатай и не коммить; пароль читай из файла в `VITRUM_KS_PASS`.
- Не нарушай инварианты: нет портов на 127.0.0.1, шифрование ссылок на диске, только https, подтверждение внешних ссылок.
- Скрытие VPN от приложений разрешено автором, но требует root и отложено (см. `AGENTS.md`); сейчас рабочий путь только исключение приложений из VPN.
- Сборки, тесты и APK: GitHub Actions (`.github/workflows/build.yml`) запускается только по тегу `v*` или вручную, APK сразу уходит в GitHub Release (pre-release). Перед тегом: `tools/build.sh tests`.
- Сборка: `tools/SETUP_ENV.sh`, `tools/FETCH_BINARIES.sh --linux`, `tools/build.sh tests|debug|release`.
- Если в телефоне включена отладка по USB или Wi-Fi, можно ставить сборку через `adb install -r`, смотреть `adb logcat` и снимать экран: это единственный способ проверить приложение на устройстве.
