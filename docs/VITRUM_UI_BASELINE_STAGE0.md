## Проверено как факт

- Архив smoke test содержит **41 PNG** и **41 XML** UI-иерархию, `result.txt` сообщает PASS. `android-runtime.log` в этом архиве пуст; это **не** тест всех потенциальных сбоев.
- Есть кадры onboarding, главной в обычном и синтетически подключённом состоянии, списка серверов с фильтрами, маршрутов, центра настроек и восьми его внутренних подразделов (маршруты открываются отдельно), игрового режима, журнала, Щита.
- Скриншот шириной 1080 px при density 480 соответствует **360 dp**; при 440 — приблизительно **393 dp**, при 400 — **432 dp**. Первичный артефакт в основном тёмный/русский при 360 dp и font 1.3; был только ограниченный светлый/английский кадр главной при 432 dp/font 1.5.
- Дополнительная baseline-матрица в `tools/clone-android16-ui.sh` записывает `baseline-matrix.tsv` с коммитом и снимает ещё **20** сценариев при 360/393/432 dp, font 1.3–1.5, тёмной/светлой темах, RU/EN, включая все девять разделов настроек, Game/Journal/Shield. CI-артефакт должен содержать пары PNG+XML для каждой строки. PNG проверяется по сигнатуре и фактическому размеру 1080×2400; пустой или устаревший XML считается ошибкой.
- Артефакт относится к `app.rayclient.clone`. Надпись «другая подпись» в `About` ожидаема из-за отдельного debug-сертификата Clone и **не является дефектом** официального APK.
- Данные `Demo.kt` синтетические (например, example.com). Запуск UI не создаёт настоящий Android TUN и не проверяет DNS/IPv4/IPv6-утечки, kill switch или переключение физических сетей.
