# Vitrum 2.1.2 — subscription privacy maintenance

**Channel:** signed **pre-release candidate** until a maintainer verifies the exact official APK on a physical ARM64 Android device. Do not present CI-only evidence as real-device VPN validation.  
**Application:** `app.rayclient` · Android 8.0+ (API 26) · ARM64 (`arm64-v8a`) · `versionCode 287` · `versionName 2.1.2`.  
**Update:** the official `Vitrum-2.1.2.apk` must retain the existing Vitrum maintainer certificate (SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`), allowing an in-place update from author-signed 2.1.1 and 2.0.0 **without uninstalling or clearing app data**. The debug fallback has a different signing identity and cannot update the official app.

## Fixed

- Removed server-controlled subscription response snippets from the error shown when no supported servers are found. HTTP headers, subscription payloads, raw exception messages and malformed link details are no longer echoed to user-visible errors.
- Added bounded, actionable error descriptions for common HTTPS failures (DNS lookup, timeout, TLS and connection problems) and response types (HTML, JSON or unknown).
- Added JVM regression tests for injected credential-like data and redaction of subscription URL details from failures.

## Repository maintenance

- Removed completed one-shot 2.1.0 and 2.1.1 publishing request workflows; retained the official signed release pipeline.
- Synchronized project handoff, changelog and GitHub security reporting guidance.
- Version 2.1.2 includes the above fixes previously merged into `main` after the published 2.1.1 tag.

## Behavior and limitations

- No changes to VPN/TUN, DNS, routing, Xray-core, server selection, stored data formats, Android package ID, minSdk, targetSdk, or signing key.
- The R8/WorkManager constructor guard added in 2.1.1 remains enabled.
- JVM tests, Debug/Clone compilation, R8 release checks and Android 13 emulator startup smoke are automated. A passing run proves only the tested source/artifact and environment.
- **Not independently verified:** VPN routing, IPv4/IPv6 or DNS leak resistance, Wi-Fi/mobile transitions, Always-on/lockdown, actual remote-server compatibility, and compatibility across all real devices.
- Stable release promotion requires confirmation of installation, launch, data preservation, connect/stop, server switch and network behavior on the actual author-signed `Vitrum-2.1.2.apk`.

## Installation and verification

1. Download the **author-signed** `Vitrum-2.1.2.apk` from the corresponding GitHub Release after the signing workflow finishes. Do not use the debug fallback for an in-place update.
2. Verify the release certificate SHA-256 against `SECURITY.md` and compare the APK SHA-256 with the checksums attached to the release.
3. Install over the existing official Vitrum without clearing application storage. Verify existing profiles, servers and subscriptions remain accessible.
4. Run the physical-device checklist in `docs/ANDROID_RUNTIME_CHECKS.md` before accepting a stable release.

**Release status and APK checksums are determined by the published GitHub Release, not by this source document.**
