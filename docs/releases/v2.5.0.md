# VITRUM v2.5.0 — DNS Route Guard & IPv6 Evidence (pre-release)

**Пакет:** `app.rayclient` · **versionCode:** 250 · **versionName:** 2.5.0 · **Android:** 8+ · **ABI:** ARM64. Обновление поверх официальной 2.4.0 при совпадении авторского сертификата.

## Что изменилось

- **DNS Route Guard:** в обычном режиме Xray сначала направляет DNS TCP/UDP на порт 53 через прокси или основной балансировщик, даже когда `defaultAction=direct` / режим «Все, кроме РФ» / обход LAN могли бы направить запрос напрямую.
- **Приоритет пользователя:** явные собственные правила для порта 53 сохраняют приоритет. Когда включены DoH, FakeDNS или `blockV6`, как прежде, порт 53 перехватывает `dns-out`.
- **IPv6:** маршрут Android `::/0` и блокирующие правила при `blockV6` не меняются. В «Щите» отдельно поясняется, что HTTP-тест через Xray-сокет не доказывает защиту IPv6 других Android-приложений.
- **Диагностика DNS:** показывает политику из конфигурации и отдельно **DNS утечки: UNKNOWN**, пока нет независимого теста. Убрано неподтверждённое утверждение о гарантированном отсутствии IPv6-утечек.
- Проверки правил и генерации конфигураций JVM; реальные `xray run -test` для трёх типовых конфигов; Android 16 UI smoke; release APK собирается только с текущим авторским ключом и проверкой его SHA-256.

## Изменение поведения и возможные ограничения

**DNS через локальный резолвер LAN** (например, 192.168.x.x) при включённом VPN может перестать работать, если тот недоступен из VPN-сервера. В таком случае требуется **явное правило direct** для нужного DNS-трафика либо выбор публичного резолвера. Приложения, исключённые из VPN, по-прежнему имеют прямой сетевой путь; VITRUM не контролирует их DNS.

DoH/DoT на 443/853 и частный DNS Android могут требовать иных маршрутов. Проверка DNS-порта 53 через конфигурацию сама по себе **не доказывает отсутствие DNS-утечек**. IPv6 timeout не является подтверждением блокировки без утечек. Тесты CI/эмулятора не заменяют проверку на физическом Android ARM64 с Wi-Fi↔LTE, системным Always-on и lockdown.

До физической проверки — **pre-release**.

## Подпись

Официальный подписанный APK должен совпадать с сертификатом автора SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`. При отсутствии оригинальных секретов подписи или несовпадении отпечатка выпуск автоматически останавливается. Контрольные суммы APK добавляются GitHub Actions при публикации.
