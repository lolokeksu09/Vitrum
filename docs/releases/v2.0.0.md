# Vitrum 2.0.0 — Experience & Reliability

Официальное обновление VITRUM 1.0.0 с улучшениями, проверенными в отдельном варианте Vitrum Clone. Номер версии: **2.0.0**. Пакет: `app.rayclient`, Android 8.0+ (API 26), ARM64.

## Что изменилось по сравнению с 1.0.0

### Интерфейс и первый запуск
- Переработанный Onboarding 2.0: три шага, нормальное размещение кнопок на Android 16, прокрутка содержимого и системная навигация «Назад».
- Уведомления запрашиваются только по нажатию пользователя, не перекрывая знакомство при первом запуске.
- Увеличенные зоны касания и адаптивные элементы управления с системным масштабом шрифта.
- Главная страница правильно прокручивается на невысоких дисплеях; журнал доступен из состояния ошибки.

### Серверы и VPN-маршрутизация
- Исправлены пустые результаты фильтров, улучшены выбор серверов, избранное и доступность TalkBack.
- Настройки маршрутов показывают, какой трафик может идти напрямую, и понятнее описывают правила приложений.
- Алгоритм маршрутизации Xray и набор протоколов не изменились.

### Приватность, диагностика и устойчивость
- Щит приватности отдельно обозначает непроверенные признаки и не выдаёт их за подтверждённую защиту.
- Поиск по настройкам и пояснениям, доступные после смены вкладки результаты диагностики.
- Предупреждение о личной информации перед копированием диагностического отчёта.
- Атомарная запись зашифрованного состояния авто-серверов, ограничение размера резервных копий.
- Понятная ошибка при отказе Android запускать VPN-службу, без запуска Xray после отказа.

## Совместимость и обновление
- **Официальное приложение:** `app.rayclient`. Клон `app.rayclient.clone` остаётся отдельным тестовым вариантом и не заменяет основное приложение.
- **Подпись:** прежний ключ автора, SHA-256 сертификата `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`. GitHub Actions проверяет его при сборке, при отсутствии/несовпадении ключа релиз не публикуется.
- **Без удаления:** если установлен VITRUM 1.0.0 с этим же сертификатом, Android должен разрешить обновление поверх и сохранить локальные настройки. Перед обновлением рекомендуется сделать зашифрованную резервную копию в приложении.
- **Не совместим с подписью:** версии, подписанные иным ключом (включая старый 0.24.1, одноразовые Debug и Clone), нельзя обновить поверх обычной установки.
- **Ядро и системные требования:** Xray 26.3.27; Android 8.0+, ARM64. Изменений криптографии или протоколов в этом выпуске нет.

## Проверено
- Android 16 x86_64 UI-эмулятор: старт Onboarding 2.0, Home, Servers и Routing; разные размеры экрана и масштабы шрифта 1.0/1.3/1.5 (PR #35).
- Успешные автоматические проверки `testDebugUnitTest`, `assembleDebug`, `assembleClone`, проверка подписи и идентификатора Clone.
- Официальная release-сборка отдельно проверяет настоящий сертификат, R8, SHA-256 артефактов, версию и точный тег.

**Граница проверки:** эмулятор не подтверждает прохождение трафика через VPN на реальном ARM64 устройстве, отсутствие DNS/IPv6-утечек или долговременную стабильность Xray. Эти проверки проводятся отдельно на телефоне.

## Файлы релиза
- `Vitrum-2.0.0.apk` — подписанная прежним авторским ключом R8 release-сборка для обычного обновления VITRUM 1.0.0.
- `Vitrum-2.0.0-debug-fallback.apk` — резервная тестовая сборка с другим ключом, не устанавливается поверх официальной.

Контрольные суммы SHA-256 для конкретных APK добавляются автоматически в GitHub Release.
