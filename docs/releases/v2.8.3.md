# VITRUM 2.8.3 — Main Package Candidate

Android 8+ · ARM64 · package `app.rayclient` · versionCode 283 · 9 November 2026.

## Changes
- Localized the main app surfaces into Russian and English: Home, Journal, Privacy Shield, bottom navigation, Game, Servers, Routing, Settings, About, Backup, and dialogs.
- Improved state protection when servers and subscriptions are deleted or updated: the active route must not be silently reset while VPN is connected or transitioning.
- Isolated demo UI data from the user profile.
- GeoData is published only after SHA-256 verification; Pinger no longer calls JNI stop for a process that was not started.
- Xray fallback download uses the official Releases Assets API; SHA-256 verification remains mandatory.
- Route preview better explains generated catch-all routes and early transport restrictions; IPv6 CIDR parsing and rule order have focused JVM regression coverage. Uncertain DNS/geo/domain/traffic paths remain UNKNOWN.

## Compatibility and limitations
- Official package: `app.rayclient`. Separate test package: `app.rayclient.clone`.
- The APK must update the previous official installation using the same maintainer certificate.
- Route-preview changes do not prove actual VPN traffic behavior or absence of leaks.
- Physical ARM64 acceptance for Xray/TUN, DNS/IPv4/IPv6, failover, kill switch, and UI on Lenovo Legion Y70 has not been completed; the device owner performs it.
- This build is intended only as a pre-release pending user verification. It is not declared a stable release.
