# Vitrum 0.24.1

Первая публикация исходников. В приложении изменился только текст «О приложении»: исходный код теперь указан по адресу репозитория (раньше было «пока не опубликован»).

**Что в приложении (с 0.24.0):** режим JSON-подписки (авто-серверы с балансировщиками панели; включается в меню подписки). Метаданные подписки, игры и Россия, щит с честной оценкой, журнал соединений, сценарии, игровой режим, русский и английский язык.

**Установка:** скачайте `Vitrum-0.24.1.apk`. Файл `Vitrum-0.24.1-debug-fallback.apk` нужен только если релиз не запускается (подписан отладочным ключом, поверх релиза не встанет).
