# Vitrum 0.24.1

First publication of the source code. The only app-visible change was the About-screen text: the source code URL now points to the repository (previously it said that the source was not yet published).

**Included since 0.24.0:** JSON subscription mode (panel load-balancer auto-servers, enabled from the subscription menu), subscription metadata, Games and Russia features, honest Shield assessment, connection journal, scenarios, game mode, and Russian/English localization.

**Installation:** download `Vitrum-0.24.1.apk`. The `Vitrum-0.24.1-debug-fallback.apk` file is only for cases where the release build does not start; it uses a debug key and cannot update an installed release build.
