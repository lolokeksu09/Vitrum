# VITRUM 2.8.1 — упрощение интерфейса

Android 8+ · ARM64 · пакет `app.rayclient` · versionCode 281.

- Главная показывает состояние VPN без повторной подписи. Длинное название сервера может занимать две строки.
- В списке серверов протокол и задержка читаются без цветных плашек. В настройках разделы оформлены строками.
- В «Маршрутах» видны счётчики правил, а кнопки профиля переносятся целиком при крупном шрифте.
- В «Щите приватности» оценка показана текстом. Убраны декоративные эффекты в журнале, игровом режиме и на экране первого запуска.

Изменения интерфейса: [PR #72](https://github.com/lolokeksu09/Vitrum/pull/72). Настройки, серверы и данные подписок совместимы с 2.8.0.

Проверка на Android 16 использует эмулятор и демонстрационные данные. Выпуск остаётся pre-release до проверки на физическом Android-устройстве.
