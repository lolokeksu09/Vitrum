# VITRUM 2.8.1 — Interface Simplification

Android 8+ · ARM64 · package `app.rayclient` · versionCode 281.

- Home displays VPN state without a repeated subtitle. Long server names can use two lines.
- Server protocol and latency are readable without colored badges. Settings sections use plain rows.
- Routing shows rule counters, and profile buttons wrap as complete controls at larger font sizes.
- Privacy Shield displays its score as text. Decorative effects were removed from Journal, Game mode, and onboarding.

UI changes: [PR #72](https://github.com/lolokeksu09/Vitrum/pull/72). Settings, servers, and subscription data remain compatible with 2.8.0.

Android 16 verification uses an emulator and demo data. This remains a pre-release until checked on a physical Android device.
