# Vitrum v2.4.0 — Privacy Shield 2.0 (Pre-release)

Android 8.0+, ARM64. Main package `app.rayclient`, versionCode 240, versionName 2.4.0. Updates official v2.3.0; the maintainer certificate is unchanged.

## What's new
- The main 0–10 value is explicitly described as an **assessment of settings and limited local checks**, not a guarantee against leaks.
- Manual diagnostics inspect common TCP ports on 127.0.0.1, then perform IPv4/IPv6 HTTP checks through a private Xray Unix socket. The primary check does not request the direct IP.
- A separate consent dialog is required to compare the IP outside the VPN, warning that the direct IP is disclosed to an external HTTPS service.
- Port and IP results are bound to the server, VPN session, network-connection epoch, and a five-minute validity period; stale results do not count as evidence of protection.
- Local TCP ports with unknown owners and a match between the direct IP and Xray exit IP are warnings, not proven leaks.
- IPv4/IPv6 errors distinguish timeout, unavailable socket, invalid response, and no response.
- The latest 12 diagnostics are kept in process memory; category comparison and reports exclude IPs, port numbers, server names, keys, and sockets. Reports **include timestamps**.
- DNS leaks remain **UNKNOWN** because there is no independent DNS observer.

## Evidence boundaries

An HTTP response through the service Xray socket is **not** proof that all Android apps are routed through the VPN, that DNS/IPv4/IPv6 leaks are impossible, or that system traffic blocking works. A local port may belong to another app. Comparing direct and exit IPs is a heuristic, not a definitive verdict. Xray Unix-socket checks use ordinary HTTP after the exit proxy, not TLS; the direct IP is requested over HTTPS only after explicit consent.

Real ARM64 Android TUN, Wi-Fi↔LTE, Always-on/lockdown, and DNS leak behavior were not verified on a device. Until manual verification, this remains a **pre-release**.
