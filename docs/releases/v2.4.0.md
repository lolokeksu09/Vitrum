# Vitrum v2.4.0 — Privacy Shield 2.0 (pre-release)

Android 8.0+, ARM64. Основной пакет `app.rayclient`, versionCode 240, versionName 2.4.0. Обновление поверх официальной v2.3.0; сертификат автора не меняется.

## Что нового

- Главное число 0–10 теперь прямо обозначено как **оценка настроек и ограниченных локальных проверок**, а не гарантия отсутствия утечек.
- Кнопка ручной диагностики выполняет просмотр распространённых TCP-портов 127.0.0.1, а затем HTTP IPv4/IPv6 через частный Xray Unix-сокет. Прямой IP в ходе основной проверки не запрашивается.
- Для сравнения IP вне VPN добавлен отдельный диалог согласия с предупреждением о раскрытии прямого IP внешнему HTTPS-сервису.
- Результаты портов и IP привязаны к серверу, сеансу VPN, эпохе сетевого подключения и пятиминутному сроку действия; старые результаты не подтверждают защиту.
- Локальные TCP-порты неизвестного владельца и совпадение прямого IP с IP выхода Xray показываются как предупреждение, а не доказанная утечка.
- Ошибки IPv4/IPv6 различают таймаут, недоступный сокет, неверный ответ и отсутствие ответа.
- История 12 последних диагностик только в памяти процесса; сравнение категорий и отчёт без IP, номеров портов, названий серверов, ключей и сокетов. Отчёт **содержит временные метки**.
- DNS-утечки остаются **UNKNOWN**, так как независимого DNS-наблюдателя пока нет.

## Границы подтверждений

Ответ через служебный HTTP-сокет Xray **не является** доказательством маршрутизации всех Android-приложений, DNS/IPv4/IPv6 leak safety или успешной системной блокировки трафика. Локальный порт может принадлежать стороннему приложению. Сравнение прямого и выходного IP — эвристика, не окончательный вердикт. Проверки Xray через Unix-сокет используют обычный HTTP после выходного прокси, не TLS; прямой IP при явном согласии запрашивается по HTTPS.

Реальный ARM64 Android TUN, Wi-Fi↔LTE, Always-on/lockdown и отсутствие DNS-утечек на устройстве не проверялись. До ручной верификации это **pre-release**.
