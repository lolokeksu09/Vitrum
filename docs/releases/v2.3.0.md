# Vitrum v2.3.0 — восстановление автопереключения (pre-release)

Пакет `app.rayclient`, versionCode 230, versionName 2.3.0. Android 8.0+, ARM64. Обновление поверх официального v2.2.0 с прежним ключом автора.

Если запуск Xray кандидата не удался, VITRUM пробует следующих кандидатов. Если ни один не ответил через служебный unix-сокет, выполняется проверяемый откат к прежнему серверу. При неудаче отката TUN сохраняется заблокированным даже при выключенном kill switch приложения. Выбор сервера меняется только после HTTP-ответа и проверки процесса; STOP/новое подключение отменяют устаревший результат.

В журнале событий добавлена отдельная запись автоматического отката. Отчёт по-прежнему содержит только типовые события, время и счётчики, без серверных адресов и ключей.

**Не проверено на устройстве.** JVM-тесты и сборка CI не подтверждают реальный VPN-трафик ARM64, DNS/IPv4/IPv6 leak safety, Wi-Fi↔LTE, Always-on/lockdown или фактический fail-closed. HTTP-ответ не доказывает отсутствие утечек. Проверки автора: `docs/ANDROID_RUNTIME_CHECKS.md`, раздел v2.3.0.

Требуется прежний сертификат автора SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`. Несовпадение или отсутствие секретов останавливают публикацию. Контрольные суммы готовых APK добавляет GitHub Actions при выпуске.
