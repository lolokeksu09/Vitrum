# VITRUM v2.6.0 — DNS Route Audit (pre-release)

Android 8+, ARM64, package `app.rayclient`; versionCode **260** / versionName **2.6.0**. Intended to install over the official v2.5.0 signed APK; author certificate must match.

## Changes
- **Strict custom DNS addresses:** numeric IPv4/IPv6 literals only, malformed IPv4 octets, truncated IPv6, bracketed addresses, zone identifiers and hostnames are excluded **without DNS lookups**. Valid entries remain in configured order, duplicates are removed. The stored input text is retained for editing.
- **Visible fallback:** if the custom DNS list contains no valid literal, the existing default resolver list is selected and Settings warns the user; malformed entries are not silently sent to Xray.
- **DNS Route Audit:** a user-initiated, offline analysis of the *generated Xray rule order* for configured DNS resolvers on TCP/UDP port 53. It reports rules that would use the proxy, internal Xray DNS, a direct connection, a block rule, mixed paths or unknown route. Explicit user IP/CIDR and port rules can override the DNS Route Guard and are shown as such.
- **Privacy Shield:** a separate configuration-only audit and conservative DNS leak state `UNKNOWN`. No IP address or domain is sent or saved by this audit.
- 13 new JVM regression tests on invalid DNS literals, fallback, DNS TCP/UDP route precedence, geo uncertainties, mixed routes and Android app exclusion.

## Limits, privacy and risks
- This audit **does not inspect live TUN packets**. The current app's saved config may differ from the running Xray instance until reconnect; no guarantee of device-wide DNS/IPv6 leak freedom.
- Browser DoH (443), Android Private DNS/DoT (853), applications excluded from Android VPN, dynamically sniffed domains and GeoIP decisions are not independently measured. Ambiguous routes remain UNKNOWN.
- Malformed custom DNS addresses that v2.5.0 previously accepted may stop being passed to Xray. The previous fallback (public preset resolvers) is retained; this may not match the user's intended private DNS provider. Settings shows warnings before use.
- The Android VPN TUN, Xray binary, default route priorities, server credentials, encrypted storage, package ID and original app signing key are unchanged. No new dangerous permissions are requested.
- No full proof of DNS/IPv6 leak-free behavior until a separate controlled test on physical ARM64 Android including Wi-Fi ↔ LTE, always-on, lockdown and split tunneling.
- This is a **pre-release** until physical device verification.
