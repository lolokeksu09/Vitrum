# Vitrum v2.1.0 — официальный подписанный тестовый выпуск

**Пакет:** `app.rayclient` (обновление существующего Vitrum v2.0.0, не установка Clone). **Совместимость:** Android 8.0+, ARM64. **Версия:** `versionCode 210`, `versionName 2.1.0`.

Включает общий код Vitrum Clone и все изменения в `main` после v2.0.0, а также два завершённых набора изменений:
- Защищённое переключение серверов без закрытия Android VPN TUN, проверка ответа Xray до выбора нового сервера, откат при неудаче (PR #56).
- Ручная проверка HTTP-доступности IPv4/IPv6 через Xray (PR #55), плюс более честный статус соединения, исправления гонок STOP/START и предварительный просмотр маршрутов (PR #41–54).

**Ограничения тестов:** Android 16 x86_64 UI smoke — только интерфейс, без реального TUN. JVM-тесты проверяют логику, но не трафик ARM64. Нет доказательства защиты от DNS/IPv4/IPv6-утечек или корректного kill switch/rollback на всех прошивках. Если браузер либо сервер недоступен, приложение не должно делать вывод «без утечек» по одному ответу HTTP. До ручных испытаний опубликован только **pre-release**.

Перед установкой сделайте резервную копию настроек. Проверьте A→B, B→A, неработающий B и откат, STOP во время смены, повторные нажатия, Wi-Fi↔LTE, IPv6 и Always-on/lockdown. На время испытаний учтите риск кратковременной потери соединения.

**Подпись:** GitHub Actions принимает только прежний сертификат автора (SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`). При отсутствии секрета или несовпадении подписи официальный APK не публикуется. SHA-256 готовых APK добавляет `build.yml` после успешной сборки.
