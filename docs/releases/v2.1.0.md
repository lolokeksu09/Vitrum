# Vitrum v2.1.0 — Signed Test Release

**Package:** `app.rayclient` (updates existing Vitrum v2.0.0; not a Clone install). **Compatibility:** Android 8.0+, ARM64. **Version:** `versionCode 210`, `versionName 2.1.0`.

Includes shared Vitrum Clone code and all changes merged into `main` after v2.0.0, plus two completed change sets:
- Safe server switching without closing Android VPN TUN; verify the Xray response before selecting the new server; roll back on failure (PR #56).
- Manual IPv4/IPv6 HTTP reachability checks through Xray (PR #55), more accurate connection state, STOP/START race fixes, and route preview (PRs #41–54).

**Test limitations:** Android 16 x86_64 UI smoke covers the interface only, not real TUN traffic. JVM tests verify logic, not ARM64 traffic. There is no proof of DNS/IPv4/IPv6 leak protection or correct kill-switch/rollback behavior on every firmware. If a browser or server is unavailable, the app must not infer "no leaks" from a single HTTP response. This was published as a **pre-release** pending manual testing.

Back up settings before installation. Test A→B, B→A, an unreachable B and rollback, STOP during switching, repeated taps, Wi-Fi↔LTE, IPv6, and Always-on/lockdown. Account for possible temporary connection loss during testing.

**Signature:** GitHub Actions accepts only the existing maintainer certificate (SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`). If the secret is unavailable or the signature differs, the official APK is not published. `build.yml` adds APK SHA-256 values after a successful build.

Documentation: `docs/ANDROID_RUNTIME_CHECKS.md`, `docs/HANDOFF.md`.
