# VITRUM 2.8.2 — Vitrum Clone Improvements in the Official APK

Android 8+ · ARM64 · package `app.rayclient` · versionCode 282 · 5 November 2026.

## Changes
- **Servers:** All/Favorites filters, country selection, and sorting are available controls that do not hide actions on narrow screens or at larger font sizes. The latency-check button remains visible.
- **Routing profiles:** select the active profile from a clear menu; creating a new profile is a separate action and remains accessible without horizontal scrolling.
- **Settings:** the Back action on nested pages remains available while scrolling long content.
- **Game mode:** choosing a server from measurement results now uses the same safe switching path as the server list. While VPN is connected or TUN is blocked, the result does not directly overwrite the selected server. The current selection is indicated.
- **Journal:** an empty filter result is distinguished from an empty event history; a filter reset is available.

Changes are based on already integrated PRs [#75](https://github.com/lolokeksu09/Vitrum/pull/75) and [#76](https://github.com/lolokeksu09/Vitrum/pull/76). Shared Clone sources were already integrated into `main`; version 2.8.2 is built from the same sources.

## Compatibility and security
- Official package: `app.rayclient`; this is an update to Vitrum, not a separate `app.rayclient.clone` app.
- Requires the original maintainer certificate (SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`). No key rotation or debug signature is allowed.
- Subscription, server, and storage formats are not migrated. Xray, TUN, DNS rules, and kill switch were not changed by this release.
- Unit tests, Xray config validation, and Android 16 UI smoke were run on change branches. Final build and version signature are verified separately during publication.

**Status:** signed official pre-release after successful CI. VPN operation, Wi-Fi/LTE switching, Always-on, lockdown, and DNS/IPv4/IPv6 leak behavior on a physical ARM64 phone are **not verified**. UI smoke with demo data is not a substitute.
