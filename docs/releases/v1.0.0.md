# Vitrum 1.0.0

First release using the 1.0 version line; the feature set and audit were completed for this release.

## Included
- VLESS, VMess, Trojan, Shadowsocks, and Hysteria2; HTTPS subscriptions, including JSON mode with auto-servers; panel metadata.
- Kill switch, automatic server failover, network-type scenarios (Wi-Fi, mobile, roaming, open Wi-Fi), VPN schedule, Privacy Shield, and connection journal.
- Routing profiles; domain, address, and port rules with validation; Other Traffic policy; per-app split tunneling; Everything except Russia mode; allowlist; Games outside VPN.
- Server measurements (HEAD, TCP, ICMP, speed), stability rating, per-app traffic, local problem report without automatic sending, and Russian/English localization.
- Audit fixes: kill switch during reconnect, app lock, validation of subscription and `/json` data, GeoIP validation after download, service races, orphaned Xray cleanup, and more. See `CHANGELOG.md` and `docs/HANDOFF.md`.
- GNU GPL v3 (version 3 only), see `LICENSE`. UI text and documentation were written independently; DUORAY code and text were not copied.
- The About screen and README disclose that AI assistance is used in development.
