# Vitrum 1.0.0

Первая версия с номером 1.0: набор функций и аудит завершены. Это отметка готовности набора, а не подтверждение проверки на устройстве.

## Что внутри
- Протоколы vless, vmess, trojan, shadowsocks, hysteria2; подписки по https (в том числе JSON-режим с авто-серверами), метаданные панели.
- Kill switch, автопереключение серверов, сценарии по типу сети (Wi-Fi, мобильная, роуминг, открытая Wi-Fi), расписание VPN, Щит приватности, журнал соединений.
- Маршрутизация: профили, правила для доменов, адресов и портов с проверкой, «Прочий трафик», раздельное туннелирование по приложениям, режим «Все, кроме РФ», белый список, «Игры мимо VPN».
- Замер серверов (HEAD, TCP, ICMP, скорость), рейтинг стабильности, трафик по приложениям, отчёт о проблеме без отправки, русский и английский язык.
- Исправления по аудиту: kill switch при переподключении, блокировка приложения, проверка данных из подписок и из `/json`, проверка geoip после скачивания, гонки в службе, зачистка осиротевшего Xray и др. История: `CHANGELOG.md`, состояние: `docs/HANDOFF.md`.
- Лицензия GNU GPL v3 (только версия 3), `LICENSE`. Тексты интерфейса и документации написаны заново, код и тексты DUORAY не копировались.
- В «О приложении» и README указано, что разработка ведётся с помощью ИИ-ассистента.

## Важно
- **Подпись.** Файлы этого релиза подписаны одноразовым ключом сборки на GitHub Actions, не ключом автора. Поверх выпуска с ключом автора (отпечаток `2c6afebf27fbbd2b288f8fb51ca6c9a7c8f4c7ce66793aa67cc04350a6f9a9a1`) они не встанут; сборки разных запусков тоже подписаны разными ключами.
- **Не проверено на устройстве** ничего, добавленное после 0.24.1. Релиз помечен как pre-release по этой причине.
- Файлы: `Vitrum-1.0.0-release-debugsigned.apk` (конфигурация release, R8) и `Vitrum-1.0.0-debug-fallback.apk` (запасная отладочная). Контрольные суммы добавляются в описание релиза автоматически.
