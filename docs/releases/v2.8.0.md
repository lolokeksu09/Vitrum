# VITRUM 2.8.0 — Native UI clarity (pre-release)

**Android:** 8+ / ARM64 · **package:** `app.rayclient` · **versionCode:** 280 · **versionName:** 2.8.0.

## Что изменено

- Главный экран теперь строится вокруг состояния VPN: статус соединения, одна большая кнопка подключения, выбранный сервер, затем проверка доступности и статистика. Убрана 300dp анимированная светящаяся сфера, большие пустые области и постоянные декоративные циклы.
- Нативная навигация Material 3 на две существующие вкладки вместо плавающей стеклянной капсулы. Переходы короткие и без масштабирования.
- AMOLED-тема с настоящим `#000000`, непрозрачными нейтральными поверхностями; сохранены фирменный фиолетовый акцент и шрифт Manrope. Светлая тема поддерживается.
- Серверы: простой читаемый список, выбранный сервер выделен умеренно, все функции выбора, переключения, избранного, пинга и длинного нажатия сохранены.
- Настройки: однотипные текстовые строки без разноцветных плиток, минимум 72dp высоты пункта, до двух строк пояснения.
- Статусы соединения `HomeStatusPolicy` подтверждаются JVM-тестами; тексты не называют запущенный VPN гарантией отсутствия утечек.
- Проверки сборки: `testDebugUnitTest`, `assembleDebug` / `assembleClone`, схемы Xray без Android TUN на Linux, Android 16 x86_64 UI smoke с демонстрационными синтетическими серверами; подпись оригинальным сертификатом только в release.

## Ограничения и совместимость

Меняется только интерфейс. Xray, `RayVpnService`, Android TUN, Kill switch, маршруты, DNS, ключи, данные подписок, форматы хранилища и пакет приложения не меняются.

Android UI smoke использует эмулятор и синтетический демо-режим, **не проверяет** реальное VPN-подключение или сетевые утечки. Внешний вид на физическом Lenovo Legion Y70, поведение жестов и системного масштаба 1.3–1.5 необходимо подтвердить вручную до stable-релиза. Приложение остаётся pre-release.
