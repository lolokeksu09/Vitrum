# VITRUM 2.8.0 — Native UI Clarity (Pre-release)

**Android:** 8+ / ARM64 · **package:** `app.rayclient` · **versionCode:** 280 · **versionName:** 2.8.0.

## Changes
- The home screen is organized around VPN state: connection status, one prominent connect button, selected server, then reachability checks and statistics. Removed the 300dp animated glowing orb, large empty areas, and continuous decorative loops.
- Native Material 3 navigation for the two existing tabs replaces the floating glass capsule. Transitions are short and avoid scaling.
- AMOLED theme uses true `#000000` with opaque neutral surfaces; the brand violet accent and Manrope font remain. Light theme is supported.
- Servers: a simple readable list, restrained selected-server highlight, and preserved selection, switching, favorites, ping, and long-press actions.
- Settings: consistent text rows without colorful tiles, at least 72dp row height, and up to two lines of supporting text.
- `HomeStatusPolicy` connection states are covered by JVM tests; labels do not imply that a running VPN guarantees no leaks.
- Build checks: `testDebugUnitTest`, `assembleDebug` / `assembleClone`, Linux Xray config validation without Android TUN, Android 16 x86_64 UI smoke with synthetic demo servers; original certificate is used only for release signing.

## Limitations and compatibility

Only the interface changes. Xray, `RayVpnService`, Android TUN, kill switch, routes, DNS, keys, subscription data, storage formats, and application ID are unchanged.

Android UI smoke uses an emulator and synthetic demo mode; it **does not test** real VPN connectivity or network leaks. Appearance on a physical Lenovo Legion Y70, gesture behavior, and system font scales 1.3–1.5 require manual verification before a stable release. This build remains a pre-release.
