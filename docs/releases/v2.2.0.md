# Vitrum v2.2.0 — журнал событий VPN (подписанный pre-release)

**Пакет:** `app.rayclient`, **versionCode:** 220, **versionName:** 2.2.0, Android 8.0+, ARM64. Устанавливается поверх официального 2.1.0 при совпадении сертификата. Не является APK `app.rayclient.clone`.

### Новое
- «Журнал» → «События VPN»: последние 40 запусков, остановок, переподключений, потерь сети, ручных/автоматических смен сервера и сбоев, с локальными отметками времени.
- Сводка количества переключений, проблем и потерь сети.
- Копирование отчёта без серверных ссылок, IP, доменов и ключей. **Отчёт содержит время событий**, просмотрите его перед отправкой.
- История хранится только в памяти процесса и очищается отдельно. Переключатель подробного журнала сетевого трафика не изменён.

**Границы проверки:** JVM unit tests, Debug/Clone/release build и Android 16 x86_64 UI smoke не доказывают VPN-трафик ARM64, DNS/IPv6 leak-free или корректную работу kill switch/rollback в реальной сети. Не называйте приложение полностью безопасным только на основании этого CI. Для проверки на телефоне используйте `docs/ANDROID_RUNTIME_CHECKS.md`.
