# Vitrum v2.2.0 — VPN Event History (Signed Pre-release)

**Package:** `app.rayclient`; **versionCode:** 220; **versionName:** 2.2.0; Android 8.0+; ARM64. Installs over official 2.1.0 when the certificate matches. This is not the `app.rayclient.clone` APK.

### Added
- Journal → VPN Events: the latest 40 starts, stops, reconnects, network losses, manual/automatic server switches, and failures, with local timestamps.
- Summary counts for switches, problems, and network losses.
- Copyable report without server links, IP addresses, domains, or keys. **The report includes event timestamps**; review it before sharing.
- Event history is kept only in process memory and can be cleared separately. The detailed network-traffic journal toggle is unchanged.

**Verification limits:** JVM unit tests, Debug/Clone/release builds, and Android 16 x86_64 UI smoke do not prove ARM64 VPN traffic, DNS/IPv6 leak freedom, or correct kill-switch/rollback behavior on a real network. Do not describe the app as fully secure based only on CI. For phone testing, use `docs/ANDROID_RUNTIME_CHECKS.md`.

**Signature:** only the original maintainer certificate, SHA-256 `8cb8b675f97239948f0b93ac4208464e856397d6141268798129c00337205c61`. Publication is blocked if secrets are unavailable or the signature differs. APK SHA-256 values are shown on the GitHub Release page after a successful build.
